Cómo se actualiza

🗓️ Calendario

TheSportsDB alimenta las próximas fechas. El actualizador conserva el último calendario bueno si la fuente falla.

📡 Marcador

El navegador consulta ESPN cada 30 segundos cuando hay partido. No hay servidor propio ni base de datos: si ESPN cae, se avisa.

🕒 Hora

Todo se muestra en hora de Colombia (UTC-5). Las horas futuras se marcan como “por confirmar” hasta que haya una fuente que las cierre.

🔗 Fuente

Cada partido enlaza a su ficha. Si un dato no se puede verificar, no se inventa: se deja pendiente.
